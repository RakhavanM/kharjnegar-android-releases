# خرج‌نگار برای اندروید

فایل‌های رسمی نسخهٔ GitHub خرج‌نگار. این مخزن فقط برای توزیع APK و راهنمای نصب است؛ سورس برنامه خصوصی می‌ماند.

[دریافت نسخهٔ ۰.۸.۲](https://github.com/RakhavanM/kharjnegar-android-releases/releases/tag/v0.8.2) · [وب‌سایت](https://kharjnegar.app) · [راهنما و پشتیبانی](https://kharjnegar.app/help) · [حریم خصوصی](https://kharjnegar.app/privacy)

## نصب و به‌روزرسانی

- اندروید ۸ یا جدیدتر؛ اینترنت برای استفاده از حساب و اطلاعات لازم است.
- فایل `kharjnegar-0.8.2-github.apk` را از Assets همان Release دریافت کنید؛ فایل‌های خودکار «Source code» فقط مستندات این مخزن هستند.
- برای ارتقا، APK را روی نسخهٔ قبلی نصب کنید؛ برنامه را حذف نکنید تا داده‌های محلی و تنظیمات قفل حفظ شوند.
- نسخهٔ GitHub پرداخت اشتراک را در مرورگر وب باز می‌کند. نسخهٔ بازار در این مخزن منتشر نمی‌شود.
- ارتقا از نسخهٔ۰.۸.۱ یا قدیمی‌تر، یک‌بار دانلود دستی می‌خواهد. از۰.۸.۲ پشتیبانی از پیشنهاد اختیاری آپدیت از این مخزن اضافه شده؛ نمایش پیشنهاد به کاتالوگ سرور وابسته است. آپدیت اجباری نیست.

## وضعیت شناخته‌شدهٔ نصب

ممکن است Play Protect پیام «hasn't seen an app from this developer before» نشان دهد. بررسی Google هنوز نتیجهٔ تأییدشده ندارد؛ انتشار با اعلام این وضعیت انجام می‌شود. این توضیح تأیید Google نیست و توصیه به خاموش‌کردن حفاظت دستگاه نمی‌کند.

## اصالت فایل

هش SHA-256 فایل‌ها در `SHA256SUMS` هر Release قرار دارد. نام بسته `app.kharjnegar` است و امضای نسخه‌های قبلی حفظ شده است.
